01 / THE ORIGIN

Before the atlas,
there was a domain.

RESTLESS was created on 8 February 2026, in Go, around a deceptively difficult idea: begin with a single domain and make API discovery intelligible.

02 / ARCHITECTURE PLATE

Two engines.
One ledger.

Source integrity is the bridge. A verified document remains traceable whether it was harvested by the Go engine or the C11 engine.

Harvest once. Verify again.

RESTMORE emits RESTLESS-compatible index.jsonl and content-addressed SHA-256 files. The import path independently checks every source hash and ignores unstructured text as a source of executable API routes.

Only validated bytes are reusable.

ETag/Last-Modified conditional GET revalidation may reuse a source after HTTP 304, but only after checking its cached bytes. Unexpected 304, tampering and mixed-host archives stop the pipeline.

03 / THE TRUST BOUNDARY

Approval is
a distinct action.

The same C11 authorization rules remain in effect. Neither a repository search nor a previously saved documentation file grants rights to send API requests.

01
One domain. One scope.

Native MAP first opens GitHub repository search for human inspection. This does not prove ownership or send a target request.

02
Proof of source integrity.

Import an OpenAPI atlas bound to the intended API server. Select 5, 25 or all eligible documented GET contracts. No guessed path qualifies.

03
Review, then AUTHORIZE.

Two separate clicks. The worker checks the approvals and exact host again before network execution; changing scope invalidates pending review.

04
Compare outputs, not guesses.

Bounded HTTPS GET, robots policy, TLS and public-IP checks, no redirects, 429/5xx stop. Audit JSON captures status, MIME and root JSON shape, not response bodies.

04 / RUN IT OFFLINE

Zero network
until you choose.

These commands operate only on RESTLESS archives already present on disk and do not initiate remote calls.

cmake -S . -B build-fusion -DRESTMORE_NETWORK=OFF -DRESTMORE_TESTS=ON
cmake --build build-fusion --config Release

# Import SHA-256 verified Botanical history
./build-fusion/restmore-cli --fusion-import .restless/botanical --out fusion-atlas

# Search declared operations, including source evidence
./build-fusion/restmore-cli --fusion-import .restless/botanical \
  --fusion-search "list pets" --out fusion-atlas

# Compare two versions without contacting the server
./build-fusion/restmore-cli --fusion-import snapshots/before \
  --fusion-compare snapshots/after --out fusion-atlas

ctest --test-dir build-fusion --output-on-failure
