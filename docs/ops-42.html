03 / Repeatable mission briefing

Inspect the source.
Export the proof.

The native C11 engine generates an offline ops-brief.json with declared routes, method distribution, source fingerprints and an explicit REVIEW_REQUIRED decision state.

# Native C11, no network access
cmake -S . -B build-ops -DRESTMORE_NETWORK=OFF -DRESTMORE_TESTS=ON
cmake --build build-ops --config Release

# Offline briefing from OpenAPI source
./build-ops/restmore-cli --import examples/openapi-petstore.json --ops-brief --out evidence

# Or from a SHA-256 verified RESTLESS archive
./build-ops/restmore-cli --fusion-import .restless/botanical --ops-brief --out evidence

# Inspect evidence/ops-brief.json
ctest --test-dir build-ops --output-on-failure
