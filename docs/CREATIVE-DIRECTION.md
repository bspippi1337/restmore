# RESTMORE / Studio Manual

**The cartographer. The typewriter. The architect. The evidence draughtsperson.**

## Creative promise

**MAP THE UNSEEN.** Subtext: the program maps what documentation **declares**, not what it has not observed. Credibility is part of the brand, not a note hidden below the fold.

## The visual voices

**Art direction:** quiet architectural grandeur, strategic mint accents, asymmetry held within a deliberate grid. No random glow and no dashboard decoration that implies live telemetry.

**Typewriter copy:** short, physical verbs. *Set the scope. Build the source library. Inspect the evidence.* Place claims beside their operational limits.

**Architect's hand:** section cuts, hatching, compass arcs, registration crosses, dimensions and contour lines. Each line has a reason.

**Forensic illustrator:** measured pencil strokes and labeled figures. Decorative arches and mountains are not real API evidence and must never be labeled as such.

## Palette

Canvas `#07101b` · Panel `#0e1b2b` · Mint `#79f9dc` · Cyan `#5ebee2` · Chalk `#eef9f7` · Muted `#96acbf` · Rules `#294057` · Gold `#e9c078` · Coral `#ff9387`.

The web uses a local system sans stack and monospace for typewriter-style annotations. Native C uses loaded system fonts where available and raylib's default otherwise. Never commit copyrighted font files.

## Design limits

Make keyboard focus visible, honor reduced motion, preserve touch targets on Android and identify demo data. A nice drawing is not a runtime validation result.
